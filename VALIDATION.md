# Validasi JSONTree Pro

Pada tampilan desktop, JSONTree Pro merender layout tiga panel dengan Monaco Editor gelap, tree graph React Flow, pencarian mengambang, minimap, serta panel generator TypeScript. Struktur contoh menghasilkan 25 node dan seluruh bagian tetap terbaca.

Pencarian `Nadia` dimasukkan pada panel graph untuk memverifikasi state pencarian terhubung ke visualisasi. Node yang cocok menerima state sorotan melalui kelas graph dan hubungan edge animasi tanpa mengubah konten editor.

Halaman `/guide` dibuka melalui navigasi dan menampilkan empat langkah penggunaan, tombol kembali ke aplikasi, serta footer legal. Routing internal berjalan tanpa kesalahan pada pratinjau statis.
